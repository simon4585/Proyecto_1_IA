# Agente de Rescate con Víctimas en Riesgo

Proyecto 1 de Inteligencia Artificial. Compara BFS, UCS, IDDFS y A* sobre un
agente que rescata víctimas en una cuadrícula con restricciones de tiempo.

## Ejecución
Desde la raíz del proyecto: python main.py

## Estructura
- modelo/: Mapa y Victima
- problema/: ProblemaRescate y heurística
- busqueda/: BFS, UCS, IDDFS, A*
- io_archivos/: lectura y validación de archivos
- interfaz/: interfaz gráfica en Tkinter
- data/: mapas y víctimas de ejemplo
- informe/: informe en PDF
